# 彭本航 · 个人 AI 档案（公开镜像）

这个仓库只做一件事：**把一份个人 AI 档案以加密形态公开存放**。任何人都能看到它存在、能校验完整性；但**没有钥匙就读不出一个字**。

**仓库内没有任何明文个人资料。**

---

## 里面是什么

原始档案共 12 个文件、3,656,036 字节：结构化档案（事实 38 条 / 时间线 23 节点 / 关系 40 条）、传记、检索索引、人格提示词、170,372 条语料（`语料_全量.jsonl.gz`）、本地 MCP 服务（5 个工具）。

以上全部被打包加密成**单个容器** `档案.v4`（4,203,413 字节）。

## 加密规格

| 项目 | 值 |
|---|---|
| 版本 | v4 |
| 加密层 | Camellia-256-CBC + HMAC-SHA256 → ChaCha20-Poly1305 → AES-256-GCM（三层级联，逐层认证） |
| KDF | Argon2id（256 MiB / t=4 / p=4）+ SHAKE256-XOF 扩展 |
| 抗量子层 | ML-KEM-1024（NIST FIPS 203）+ SHAKE256-512 |
| 认证因子 | ① 口令 ② 64 字节密钥文件 ③ 容器内封装的 ML-KEM-1024 私钥（被①②包裹） |
| 长度隐藏 | 64 KiB 整数块填充 |
| 篡改检测 | 头部整块进 GCM AAD；任一字节改动即拒绝解密 |

## 解密

详见 [`解密方法.md`](./解密方法.md)。需要同时持有**口令**与**密钥文件**，两者均不在本仓库。

```powershell
python vault_v4.py info --in 档案.v4
python vault_v4.py decrypt --in 档案.v4 --outdir 还原 --pass "<口令>" --keyfile "<密钥文件.bin>"
```

## 设计原则

1. **柯克霍夫原则**：算法全部公开，安全性只依赖密钥保密。
2. 三层不同族算法级联：任何一层将来被攻破，其余仍在。
3. ML-KEM-1024 抵抗未来的量子计算攻击。
4. 不做“自研保密算法”——未经验证的自研算法只会更弱。
